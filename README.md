# Avalonia Custom Controls

A library of modern, stylish, and highly customizable controls for XAML applications based on **Avalonia UI**. This project is designed for developers who need ready-to-use solutions for building custom interfaces.

## Repository Structure

The project is divided into two main parts:
* **`HinataNET.Controls`** — A class library containing the source code for all controls (`.axaml` and `.cs` files).
* **`HinataNET.Demo`** — A demo application where you can run and test all controls in real-time.

## Available Components

Currently, the library includes:
* **Glass Auth Form** — An authentication form with a Frosted Glass effect.

*(The list is growing. New controls are released weekly).*

## How to Use

Since the library is under active development, the easiest way to use the components in your project is:

1. Clone this repository:

       git clone https://github.com/hinata-net/Avalonia-Custom-Controls.git

2. Open `HinataNET.AvaloniaUI.slnx` in your IDE (Visual Studio, Rider) and run the **`HinataNET.Demo`** project to see the controls in action.
3. To use a specific component in your project, simply copy the corresponding `.axaml` (and its associated `.cs` code-behind file, if applicable) from the `HinataNET.Controls` folder and set up your `ResourceDictionary` or XAML namespaces.
